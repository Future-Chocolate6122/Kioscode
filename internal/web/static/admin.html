¿Cómo crear la clave?

La clave tiene los mismos permisos que el usuario de UniFi que la crea. Lo recomendable es un usuario solo para el tótem:

  1. En UniFi OS Server, en Admins & Users, cree un administrador local (por ejemplo totem-api), no una cuenta de ui.com, con una contraseña larga.
  2. Dele acceso solo a la aplicación Network, sin Protect, Access ni otras.
  3. En Network, dele el permiso más bajo que permita administrar la red (suele llamarse «Full Management» o «Admin»). No sirven «Hotspot» ni «Solo lectura» (View Only): crear vouchers requiere permiso de escritura.
  4. Entre en UniFi con ese usuario y cree la clave en Network → Settings → Control Plane → Integrations. Cópiela: UniFi solo la muestra una vez.
  5. Péguela aquí, pulse Guardar y luego Probar conexión con UniFi. Si responde 403, el permiso se queda corto.

Cada servidor de UniFi tiene sus propias claves: si cambia de servidor, cree una en el nuevo.
